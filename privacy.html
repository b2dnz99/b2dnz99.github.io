Grok Health Privacy Policy

Last updated: 18 November 2026

Grok Health is a private, single-user tool run by Parvez Khan for his own use. It has no other users.

What data it accesses

With read-only permission granted through Google sign-in, it reads the owner's own Google Health data: activity and fitness, health metrics and measurements, sleep, and irregular rhythm notifications.

How the data is used

The data is used only to give the owner summaries and insights through his personal assistant. It is never sold, shared with third parties for advertising, or used for any other purpose. The app cannot write or change any health data.

Storage and security

Access tokens are stored as encrypted secrets on the owner's private assistant computer. Health data is kept only as long as needed to answer the owner's requests.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
